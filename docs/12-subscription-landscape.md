# 요청 반영: 재로그인 · 구독 · 가로 화면 — 2026-11-20

## 1. 로그인 상태에서 구매하기 → 다시 로그인 화면
| 구분 | 내용 |
|---|---|
| 원인 | 배포 서버에 DB 주소(DATABASE_URL)가 없어 회원 정보가 서버 메모리에만 있음 → Vercel이 다른 서버 인스턴스로 요청을 보내면 "모르는 사람"이 되어 로그인이 풀림 |
| 근본 해결 | Vercel 환경변수에 Supabase DATABASE_URL 등록 (DB 비밀번호가 필요해 보호자가 직접) |
| 코드 보강 | 공개 화면(책 상세 등)은 토큰이 틀려도 손님으로 보여 줌 → 보기만 했는데 로그아웃되는 연쇄 방지 / 로그인이 풀렸을 땐 로그인 화면에 이유 안내 |

## 2. 구독 (월 소장권)
| 항목 | 정한 내용 |
|---|---|
| 방식 | 월 N권 소장권 — 고른 책은 내 서재에 영구 소장 |
| 요금 | 월 6,900원 · 매달 3권 (한 권에 약 2,300원) |
| 남은 소장권 | 다음 달로 넘어가지 않음 (매달 3권 새로 채움) |
| 무료 체험 | 없음 — 소장권은 영구 소장이라 체험 후 해지로 무료 소장하는 악용을 막기 위함 |
| 해지 | 해지 예약 → 기간 끝까지 사용 가능, 받은 책은 계속 남음 |
| 보호자 확인 | 구독 시작·해지·소장권 사용 모두 PIN |
| 결제 | 테스트 결제(돈 안 나감) — 기간이 지나면 자동 갱신 / 구글 플레이·애플 구독 검증 코드 준비 |
| DB | 마이그레이션 004: subscription_plans, subscriptions, subscription_charges, library.source |

API: `GET /subscriptions/plans`, `GET /subscriptions/me`, `POST /subscriptions/test/checkout`, `/verify`, `/cancel`, `/resume`, `/redeem`

## 3. 가로 모드 반응형
| 화면 | 가로일 때 |
|---|---|
| 전체 | 폭 480 고정 → 최대 1100으로 넓게, 앱 회전 허용 |
| 읽기 | 그림 왼쪽 · 글 오른쪽, 돌려도 보던 쪽 유지 |
| 상세 | 표지 왼쪽 · 설명 오른쪽 |
| 목록(카테고리·검색·홈 인기) | 2칸 |
| 내 서재 | 표지 격자 칸 수 자동 (폭에 맞춰) |
| 입력 화면(로그인·가입·계정·결제·구독) | 최대 560 폭으로 가운데 — 너무 길게 늘어나지 않게 |

## 검증
- 서버 테스트 85개 통과 (구독 8개 × 메모리·PostgreSQL, 구글·애플 구독 검증 2개 포함)
- 구독 테스트: 시작·중복 방지·남의 영수증·3권 받기·4권째 거절·한 달 뒤 자동 갱신(날짜 앞당겨 시험)·해지 예약·만료 후 책 유지·재구독
- 화면: 세로(390×844)·가로(844×390) 캡처, 구독 가입 → 소장권 받기 → 내 서재 → 해지 예약, 읽는 중 회전 시 같은 쪽 유지
