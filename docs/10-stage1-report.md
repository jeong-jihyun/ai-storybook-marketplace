# 1단계(기본 앱) 개발 결과 — 2026-11-19

설계서 10장 1단계: 모노레포, RN 앱, 홈·카테고리·상세, 샘플 데이터, API 연동

## 만든 것
| 구분 | 내용 |
|---|---|
| 모바일 화면 | SCR-001 스플래시, 003 홈, 004 카테고리(주제·나이), 005 검색, 006 상세, 미리보기(BOOK-005), 009 내 서재·015 마이(안내 화면) |
| API | `/home`, `/categories`, `/books`(카테고리·나이·정렬·페이지), `/books/search`, `/books/bestsellers`, `/books/:id`, `/books/:id/preview`, `/books/:id/pages/:page`, `/health`, Swagger `/api/docs` |
| 데이터 | 카테고리 5개, 동화 10권(권당 8쪽, 원고 직접 작성), 표지·삽화 90장(코드로 그린 그림, 유료 AI 미사용) |
| DB | 설계서 5장 전체 테이블 마이그레이션 + 시드 SQL (여러 번 넣어도 안전) |
| 저장소 전환 | `DATABASE_URL` 있으면 PostgreSQL, 없으면 시드 데이터 (무료 배포는 시드 모드) |

## 검증
- API 테스트 26개 통과 (시드 13개 + PostgreSQL 13개, 같은 시나리오)
- 모바일 타입체크 통과, 웹 빌드 성공
- 폰 크기(390×844) 화면 16장 캡처 확인, 화면 이동(홈→상세→미리보기→뒤로) 자동 확인
- Vercel 빌드 성공, 서버리스 함수로 API·그림·Swagger 응답 확인

## 1단계에서 일부러 막아 둔 것
- 구매하기: 안내 창만 표시 (2단계 결제·서버 검증)
- 미리보기 범위 밖 페이지: 서버가 `403 PURCHASE_REQUIRED` 로 차단
- 내 서재·마이: "곧 열려요" 안내
